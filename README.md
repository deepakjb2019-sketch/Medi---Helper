# Freedom Finders — North India Travel Specialist

A responsive single-page travel agency website prototype.

## Files
- index.html — website structure/content
- styles.css — responsive premium styling
- script.js — mobile menu, reveal animations, WhatsApp enquiry

## Before launch
1. Replace the WhatsApp link in index.html/script.js with the agency's real WhatsApp number.
2. Replace demo Unsplash images with licensed/owned travel images.
3. Add real package details, reviews, contact details and legal/privacy pages.
4. Connect a domain and hosting.

The current enquiry form opens WhatsApp with the entered trip details.
